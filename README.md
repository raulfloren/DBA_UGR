# 📚 Diseño Basado en Agentes (DBA)
## Proyectos y Prácticas de Ingeniería Informática

Este repositorio contiene la implementación y documentación de las prácticas realizadas para la asignatura **Diseño Basado en Agentes**, centradas en el desarrollo de sistemas de agentes inteligentes utilizando el framework JADE (Java Agent Development Framework) y diversas estrategias de Inteligencia Artificial.

## 🛠️ Tecnologías y Conceptos Clave

* **Lenguaje:** Java
* **Framework de Agentes:** [JADE](http://jade.tilab.com/)
* **Algoritmos y Estrategias:**
    * Búsqueda Heurística en Tiempo Real (LRTA\*)
    * Máquinas de Estados Finitos (FSM) para el comportamiento
* **Comunicación:** Protocolos estándar FIPA-ACL (Request, Inform, Propose, Query-Ref)
* **Entorno:** Simulación en cuadrícula 2D
